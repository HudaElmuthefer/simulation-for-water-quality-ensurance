# Water Quality Simulation for Euphrates River

## 📌 نبذة عن المشروع

برنامج محاكاة متقدم بـ **MATLAB** لدراسة جودة المياه وتأثير المعاملات المختلفة على الملوثات في نهر الفرات.

يركز البحث على:
- محاكاة تركيزات الملوثات في نهر الفرات
- دراسة تأثير متغيرات مختلفة على جودة المياه
- توقع سلوك الملوثات وفقاً لمعايير WHO
- توليد نتائج دقيقة قابلة للتطبيق العملي

---

## 🎯 الأهداف الرئيسية

✓ توفير أداة علمية للباحثين والمتخصصين
